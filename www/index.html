Publish to your repo

Sync pushes notes to a GitHub repo you own, so the web app can read them from anywhere. This device writes one file of its own, so several devices can share a repo without overwriting each other.

Use a fine-grained token limited to that one repo, Contents: read and write. It is stored on the device in plain text, so a lost device means a token that can write to that one repo and nothing else.

Device

Note names use this. The device's clock runs on UTC, so without it a note spoken at ten in the morning is filed under whatever hour it is in Greenwich.

A soft tick on each press. E-paper takes a moment to redraw, and without it the device reads as unresponsive.

Syncing more often wakes the radio more often, which drains the battery faster.
